Codex has retired now runs on its named replacement.

Landed as [#696](https://github.com/ndycode/codex-multi-auth/pull/696),
[#697](https://github.com/ndycode/codex-multi-auth/pull/697) and

Retired model ids keep working and run on their replacement; see
`docs/configuration.md` for the table. Accounts and pools are unchanged.
